# 현황

기준: 1단계(현황판 + 클론·열기) 구현이 `main`에 합쳐진 상태. 버전 `0.1.0`, 원격 저장소 없음(아직 GitHub에 올리지 않음).

## 검증 근거

| 근거                                              | 결과                                                                                |
| ------------------------------------------------- | ----------------------------------------------------------------------------------- |
| `pnpm typecheck`, `pnpm lint`                     | 통과(로컬, 맥)                                                                      |
| `pnpm test`                                       | 단위 테스트 93개 파일 1142개 통과(로컬, 맥)                                         |
| `pnpm test:e2e`                                   | 화면 테스트 51개 통과(로컬, 맥, 가짜 GitHub 서버)                                   |
| `CSC_IDENTITY_AUTO_DISCOVERY=false pnpm dist:dir` | 서명 없는 맥 arm64 앱 `release/mac-arm64/Gdesk.app` 생성, 내장 git 2.53.0 실행 확인 |
| GitHub Actions(CI·릴리스)                         | **한 번도 돌지 않음**. 원격 저장소가 없다.                                          |
| 실제 github.com 대상 실행                         | 자동 테스트 근거 없음. 모든 자동 테스트는 가짜 GitHub 서버를 쓴다.                  |

## 남은 일

우선순위 순서다. 1~3은 1단계를 배포하기 위한 일이고, 4부터는 다음 단계 범위다.

1. **저장소를 GitHub에 올리고 CI를 처음 돌리기.** 윈도우·리눅스 단위 테스트, 리눅스 화면 테스트, 세 OS 패키징을 이때 처음 확인한다. 윈도우 askpass(`.bat`)와 클론 취소 정리도 여기서 확인한다.
2. **배포 준비물 넣기.** OAuth App 등록(Device Flow 켬)과 `GDESK_GITHUB_CLIENT_ID` 변수, 앱 아이콘(지금은 Electron 기본 아이콘), 서명 인증서(맥·윈도우, 선택).
3. **첫 릴리스와 업데이트 경로 확인.** 태그 → 초안 → 게시 → 설치된 이전 버전이 새 버전을 찾는지(OS별 방식).
4. 다음 단계 Git 작업: 최신 내용 받기(fetch/pull), 브랜치 전환, PR 체크아웃. 내장 git 실행기(`runGit`)는 명령 일반 실행부라 그 위에 더한다.
5. 다음 단계 PR 처리: 앱 안 PR 상세 화면, 코멘트·승인·머지. 들어오면 PR·알림 클릭이 앱 안 상세로 갈 수 있다. 지금 목록 클릭은 모두 GitHub 웹으로 간다.
6. 앱 창을 닫아도 갱신, 메뉴바·트레이 아이콘, OS 알림. 지금 동기화 엔진은 창이 모두 닫히면 멈춘다.
7. Home의 사용자 정의 검색 조건 카드(예: 라벨이 bug인 열린 이슈). 지금 카드는 정해진 5종이다.
8. 앱 안 포크 생성. 지금 Fork 버튼은 GitHub 포크 페이지를 연다.
9. 여러 계정 전환, GitHub Enterprise Server. 지금은 github.com 계정 하나이고, 계정이 바뀌면 이전 계정 데이터를 지운다.
10. 한국어·영어 외 번역(기여자가 `src/renderer/locales/<언어>/` 추가).

## 막힌 것

- CI·패키징 검증은 원격 저장소가 생겨야 할 수 있다.
- 서명·공증은 인증서가 생겨야 할 수 있다.
