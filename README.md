# Gdesk

오픈소스 메인테이너를 위한 GitHub 현황판 데스크톱 앱. 여러 저장소의 PR·이슈·리뷰 요청·CI·릴리스·스타·알림을
한 화면에서 보고, 저장소를 클론해 에디터로 바로 연다. 맥·윈도우·리눅스 지원, MIT 라이선스.

## 개발

```bash
pnpm install
pnpm dev          # 개발 모드 실행
pnpm typecheck    # 타입 검사
pnpm lint         # 코드 규칙 검사
pnpm test         # 단위 테스트
pnpm test:e2e     # 화면 자동 테스트 (가짜 GitHub 서버 사용)
```
